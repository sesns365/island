# 特教研習島嶼

台東大學特教師培生研習的多人 3D 闖關島。學員打開固定連結就能加入，不需帳號。

**學員連結（固定）：** https://sesns365.github.io/island/

## 講師
1. 在投影的電腦打開同一個連結，按加入畫面最下方的「講師登入」，輸入講師密碼
2. 主控台的「QR Code」可以投影學員連結
3. 之後用同一台電腦、同一個瀏覽器打開，會自動進入講師主控台（抽籤名單也存在這台電腦）

## 互動功能（主控台）
- 即時投票：輸入題目與選項後發布，學員手機跳出投票框，「投影結果」顯示長條圖
- 想法牆：輸入引導問題後開放，學員從左側「想法牆」或島上布告欄貼便利貼，「投影想法牆」全班看
- 聊天：學員按「說話」，句子會浮在角色頭上；主控台有聊天紀錄，可暫停聊天
- 「下載互動紀錄」一次匯出聊天、想法與投票（紀錄存在講師這台電腦，結束前記得下載）

## 學員
打開連結，先選角色、再輸入暱稱，等講師按「登島」。

學校網路擋連線時，可在連結後面加上 `?broker=hivemq` 改用備用伺服器（講師與學員要一致）。
需要另開一座獨立的島時，可用 `?setup` 打開場次設定頁。
