# 特教研習島嶼

台東大學特教師培生研習的多人 3D 闖關島。學員打開講師給的連結就能加入，不需帳號。

## 講師
1. 打開 https://sesns365.github.io/island/
2. 輸入講師密碼、研習名稱與場次代碼，按「建立場次，產生學員連結」
3. 把學員連結或 QR Code 分享出去，再按「進入講師主控台」

每個場次代碼是獨立的一座島；不同班級用不同代碼即可。

## 學員
打開講師給的連結（或在首頁輸入場次代碼），選角色、輸入暱稱，等講師按「登島」。

學校網路擋連線時，可在連結後面加上 `&broker=hivemq` 改用備用伺服器（講師與學員要一致）。
